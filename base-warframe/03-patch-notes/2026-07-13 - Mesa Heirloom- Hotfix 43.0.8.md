# Patch note : Mesa Heirloom: Hotfix 43.0.8
Date : 2026-07-13
Source : https://forums.warframe.com/topic/1516479-mesa-heirloom-hotfix-4308/

Image Description: Towering over the Drifter in the Dry Dock is a Vessel. Pale skin with intricate scar patterns cover this sleeping giant as we see the vastness of space behind.

Our TennoLive 2026 Relay gave players the ability to customize their Vessel as we set sights on Tau. While the Relay is now retired for another year, this hotfix brings Vessel customization for all Tenno!

Additions:

- Added Vessel customization to all Dry Docks (including those in Dojos).
