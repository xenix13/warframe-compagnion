# Patch note : Amir’s Shockwave: Hotfix 43.5.1
Date : 2026-08-12
Source : https://forums.warframe.com/topic/1519795-amir%E2%80%99s-shockwave-hotfix-4351/

Fixes:

- Fixed Clients crashing when encountering certain Surge Eximus units.
- Fixed the Cronus Blueprint only dropping once from the Vor fight.
- Now it's a guaranteed drop each time you defeat Vor.

- Fixed Sirius' Light Sanctuary VFX being invisible for players with Particle Quality set to Low (or on platforms without access to this setting).
- Fixed Vena not using her Talons and targeting enemies as an on-call Crew member.
- Fixed some cases of "Fable Master" appearing instead of the intended "Fablemaster" in Amir's Fables & Frontiers.
- Fixed Amir forgetting to clean up a few items from the internet cafe when setting up for Höllvandeim in the Höllvania Central Mall.
- Fixed minor performance issues related to Orion's Black Hole's VFX.
- Fixed Orion's Astral Shell ability's VFX sometimes appearing white upon recast.
- Fixed various script errors related to Sirius & Orion's Celestial Clash.
- Fixed a script error related to Xaku's The Lost ability.

For list of known issues that are on our radar, visit our dedicated thread: https://forums.warframe.com/topic/1519687-known-issues-amirs-shockwave/
