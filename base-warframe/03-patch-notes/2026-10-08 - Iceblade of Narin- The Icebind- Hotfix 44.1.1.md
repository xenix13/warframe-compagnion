# Patch note : Iceblade of Narin: The Icebind: Hotfix 44.1.1
Date : 2026-10-08
Source : https://forums.warframe.com/topic/1527669-iceblade-of-narin-the-icebind-hotfix-4411/

The Icebind Changes & Fixes:

- The Icebind's voting timer no longer starts immediately once all players have selected a Cryobell. Now, the Host will have the option to start the timer, so players can discuss and strategize with the Cryobells available to them.
- Additionally, the timer will begin automatically if 3 players have voted on a Cryobell.

- Removed the ability to throw the Cryo Core as it was causing cases of function loss.
- Tweaked the VFX of the damaging zone around the Entropy Orb.
- Fixed Orokin Vaults being able to spawn in The Icebind missions, which sometimes would have Side Objectives spawning inside them.
- Fixed losing a squad member resulting in the mission being progression stopped if a Side Objective was started before they left.
- Fixed enemy spawning issues when attempting to complete a Side Objective after the mission completion requirements have been met, notably in Excavation missions.
- Fixed the Indomitable Ice side objective's collision remaining after it disappears.
- Also fixed cases of players getting stuck in the side objective when it spawns in.

- Fixed various edge cases of invulnerability states negating Cryo Core health damage.
- Fixed only Arson Eximus being able to spawn if the Inferno Mission Bind was active.
- Now other Eximus units can spawn, just at a lower rate.

- Fixed being able to equip multiple of the same Warframe in The Icebind by changing loadouts during the mission countdown.
- Fixed certain voice lines in the Glacial Laboratory being incorrectly attributed to Cephalon Melica, instead of another figure.
- Also fixed the data pads using the wrong name for the context action.

- Fixed squadmates being able to interact with Log Data Pads in the Glacial Laboratory before they have unlocked them.
- Fixed being able to fall through the map into the Glacial Laboratory (treasure room) by using /unstuck.
- Fixed cases of item priority sorting not applying to rewards from The Icebind in the End of Mission screen.
- Fixed letting a random Cryobell be selected in the vote (ie. no one voted) resulting in squadmates seeing different Cryobells selected.
- Fixed the red border remaining around the Cryobell key if a player equipped and then unequipped a duplicate Warframe in the mission start menu.

Riven Splicing Changes & Fixes:

- Players can now hover over Rivens with no compatible traits in the Riven Splicing screen to see their traits.
- Fixed Weak Point Damage Spliced Traits not applying the bonus damage.
- Fixed Rivens with a Spliced Trait incorrectly doubling the Kuva cost when Cycled.
- Fixed the selected Riven not remaining selected when entering the Riven Splicing menu.
- Fixed cases of Riven Mods with spliced traits being cut off when swapping between the Splicing and Fusion menus.

Other Fixes:

- Fixed being able to take 6 player squads into non-Icebind missions.
- Fixed Security Bypass pathing not always picking the closest Terminal.
- Fixed Banshee becoming permanently invulnerable due to an interaction with Gaseous Quake.
- Fixed The Icebind and Archimedea modifiers only applying to the Primary Son when using Sirius & Orion.
- Fixed reviving as Sirius & Orion resulting in them falling through the map.
- Fixed the skin on the Amir Gemini Skin appearing overly green.
- Fixes towards the Cryobell Sumdali being blindingly bright in the Drifter Camp.
- Fixed a crash related to the No Pets modifier in Archimedea missions.
- Fixed being unable to skip The Hex kissing cutscenes.

Script Error Fixes:
Script errors mean that something went wrong when the game client was executing a script, which can have various outcomes. Usually it means the related content didn’t function properly under specific circumstances — often we don’t actually know what the error outcome was, so we list it as a Script Error fix to indicate it was addressing an unintended behaviour.

- Fixed a script error related to revival Tombstones in The Icebind.
- Fixed various script errors related to The Icebind mission start screen (including countdowns, and more).
- Fixed a script error when opening a chest in The Icebind.
- Fixed a script error related to Entropic Crystals caused by the Entropic Overload Bind.
- Fixed a script error related to the Entropy Orb side objective in The Icebind.
- Fixed a script error related to the Parasitic Light tactical bind in The Icebind.
- Fixed a script error related to the Signal Chain side objective in The Icebind.
- Fixed a script error related to a Flare KIM conversation in the POM-2.
- Fixed a script error if Protea died while ragdolling during Temporal Anchor if an Entropic Overload bind was active in The Icebind.
- Fixed a script error related to Summulysts.
- Fixed a script error related to Cascadia Empowered.
- Fixed a script error caused by an interaction between Kullervo's Collective Curse and certain Duviri Decrees.
- Fixed a script error when hovering over Abilities and cycling through tabs quickly.
