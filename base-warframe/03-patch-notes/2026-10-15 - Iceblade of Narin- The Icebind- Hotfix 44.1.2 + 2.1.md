A series of new Prologue Quests are available in the Codex!

These short Prologue Quests set the stage for the start of our journey. Players who have completed both The Hex and The Old Peace quests will see the Tau Prologue Series in their Codex upon login.

Changes:

- Added a shortcut to the Riven Splicing menu while on the Riven Cycling screen.
- Updated the on-hover Lock Riven Trait description to specify that Locking a trait also locks the number of positive and negative traits when cycling.
- Reduced the Bronco Prime Barrel's Ducat price from 45 to 25 due to changes in its rarity from Void Relics.

The Icebind Changes & Fixes:

- Added SFX to various elements in The Icebind, including SFX for connecting and reconnecting a Signal Bridge, and more.
- Fixed cases of returning players from a Host Migration not being transported to the treasure room if the mission objective was completed and extraction was paused due to an active Side Objective.
- Now, the active Side Objective will be cancelled for returning players so they can properly extract.
- Also fixed cases of returning hosts loading into a mission by themselves instead of the treasure room with the rest of their squad.

- Fixed certain Mars Excavation Cryobells resulting in players not being teleported to The Icebind's treasure room if the final Side Objective was Cryothermia.
- Fixed issues with the “Take Cryobell” context action.

Top Fixes:

- Fixed Ash marking enemies with Bladestorm and then using Transference causing the marks to remain, but Bladestorm not being performed on them.
- Fixed Client Chroma's Elemental Ward element always being Heat, regardless of emissive tint.
- Fixed Nova's Wormhole spawning far from her if it's aimed directly upwards.
- Fixed Secondary Enervate being able to proc infinitely off of Zephyr's Tornados.

Fixes:

- Fixed Uriel's Infernum Augment using the incorrect SFX for the explosion sounds.
- Fixed a [PH] appearing next to Slam Damage in the Riven Splicing menu.
- Fixes towards the desaturated areas on the Saryn Velenosa Skin becoming vibrant following our metal shader changes.
- Fixed Citrine Prime's shoulder attachment offsets being asymmetrical.
- Fixed material issues on the Harrow Profitas Helmet.
- Fixed being able to own multiple copies of the Kyzen and Karotic Signas.
- This offered no benefit to players, other than cluttering their list of Signas in customization menus!
- Fixed the glass in the Personal Quarters appearing almost white on lower spec devices.
- Fixed Commandeered Volt Prime's electrical beam VFX not being removed after the ability ends.
- Fixed an additional rare case of Inaros being revived with function loss if he died at the start of casting Sandstorm with an item (ex: Power Cell) in his hands.
- Fixed a map hole in the Yuvan Peak Captura Scene.
- Fixed various blocking volumes appearing in The War Within Choice Captura scene.
- Fixed the Circuit "Choose Your Path" screen overlapping the friends menu if you join a Friend's Circuit session in progress without yet having chosen your weekly path.
- Fixed opening a Chatlinked item while in the "Ring a Cryobell" screen causing the menus to overlap.

Script Error Fixes:
Script errors mean that something went wrong when the game client was executing a script, which can have various outcomes. Usually it means the related content didn’t function properly under specific circumstances — often we don’t actually know what the error outcome was, so we list it as a Script Error fix to indicate it was addressing an unintended behaviour.

- Fixed a script error caused by resource containers exploding from Mirage's Sleight of Hand while she is dead.
- Fixed a script error caused by Jade's Symphony of Mercy going on cooldown (ex: in a Sanctuary Onslaught mission).
- Fixed a script error when hovering over pop-ups.
- Fixed a script crash at the end of the Surge Eximus' speed ability.
- Fixed a script error in the Operator/Drifter loadout menu.
- Fixed a script error in a Warframe's Configuration screen in Teshin's Cave in Duviri.
- Fixed a script error when backing out of a menu.
- Fixed a script error related to buff notifications.
- Fixed a script error when hovering over different categories in the Railjack menu.
